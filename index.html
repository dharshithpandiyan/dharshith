Machine Learning Prototype

Animal Health Predictor

01

Overview

A full-stack prototype blending backend architecture with machine learning. This project aims to assess animal health using image recognition combined with symptom-based inputs.

02

Problem

Early identification of health risks in livestock and domestic animals is critical but often delayed due to lack of immediate veterinary access.

03

Architecture & Technology

The application is split into a robust Java-based backend handling user flow, and a Python microservice for model inference.

  • Backend: Java Servlets, JDBC, Apache Tomcat
  • Database: MySQL
  • Machine Learning: Python, PyTorch
04

Machine Learning Implementation

Leveraging MobileNetV3 Small for efficient image classification across 7 animal classes (Dog, Cat, Cow, Goat, Sheep, Horse, Chicken).

66.67% Test Accuracy
66.90% Weighted F1
PASS Safety Gate

Note: This is an academic research prototype, not intended for production veterinary diagnosis.

05

Future Improvements

Focusing on dataset augmentation, transition to an API-first framework (e.g., Spring Boot), and improving the model's confidence thresholds.
